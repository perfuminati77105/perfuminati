theme customization project. The **master chronological log** lives at
[`../PROJECT_PROGRESS.md`](../PROJECT_PROGRESS.md) — read that first for a
timeline of every change. This folder holds supporting detail documents
referenced from that log.

## Conventions

- Every doc uses the actual date it was written (`YYYY-MM-DD`), not a
  placeholder.
- Docs are additive — never delete history, only add new dated files or
  update the two living reference docs (`README.md`, `architecture.md`).
- `PROJECT_PROGRESS.md` is the source of truth for "what happened when";
  files in this folder go deeper on a single topic.
